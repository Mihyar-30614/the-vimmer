# New Room Content Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 12 new vim-concept rooms (4 per tier) plus a small `bo` schema extension that lets a room pin buffer-local options before play starts.

**Architecture:** Each room is one self-contained Lua file under `lua/rooms/<tier>/` matching the existing schema. Twelve new files; no changes to existing rooms. One `play.lua` patch threads `room.bo` / `phase_data.bo` into `vim.bo[play_buf]` before the key handler installs. One new spec block in `rooms_spec.lua` asserts all 12 new IDs load and validate.

**Tech Stack:** Lua 5.1 / LuaJIT (runtime is Neovim's LuaJIT; busted runs plain Lua 5.1), Neovim Lua API (`vim.bo`, `vim.api`), busted for headless validation.

**Spec:** `docs/superpowers/specs/2026-05-14-new-rooms-design.md`
